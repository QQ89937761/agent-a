# 微信独立记忆与共享记忆库

每个已连接的微信用户都有独立的长期记忆。普通聊天、自动记忆提炼和 memory_* 工具只使用当前账号的库；不自动检索共享资料。桌面端原有记忆库保持独立，旧资料不自动分配给新账号。

## 使用方式

| 消息 | 行为 |
| --- | --- |
| 记住，我喜欢简洁的回复 | 记录到当前账号的独立库 |
| 共享记忆库 查询：公司地址 | 查询公共资料，所有已授权微信账号可用 |
| 共享记忆库 列表：2 | 查看第 2 页，每页 20 条 |
| 共享记忆库 保存：公司地址在 A 栋 | 管理员保存公共资料 |
| 共享记忆库 修改：12：公司地址改为 B 栋 | 管理员修改编号 12 的资料 |
| 共享记忆库 删除：12 | 管理员删除编号 12 的资料 |
| 共享记忆库 帮助 | 查看指令说明 |

前缀按每条消息生效。消息中间提到“共享记忆库”不会切换，旧的“共享”前缀不再触发。共享命令不进入普通聊天历史，也不交给模型自动提炼为私人记忆。共享维护采用明确指令，不能通过自称管理员或提示词修改权限。

关闭远程操控时，账号仍可以聊天和管理自己的记忆，并按共享库权限查询或维护公共资料。此时只开放六个 memory_* 工具，不开放文件、代码、项目索引或电脑操作工具。

## 管理员身份

首次启用时，把第一个连接的账号固定为共享库管理员。以 iLink 验证的用户身份绑定；同一微信重新扫码得到新的机器人 ID 时继续使用原来的记忆及管理员身份。旧连接没有用户 ID 时按原机器人 ID 绑定，不能凭备注猜测身份。

重启、排序、修改备注和解绑都不会自动转交管理员权限。管理员解绑后，已授权的其他账号继续可读，写入暂停。需要更换时，在桌面设置 → 消息连接 → 微信 → 记忆库设置中选择一个已连接账号并确认。

## 存储、备份与同步

- 独立库：`data/weixin-memory/accounts/<身份摘要>/memory.sqlite3`。
- 身份与管理员绑定：`data/weixin-memory/bindings.sqlite3`。
- 共享库：`data/shared-memory.sqlite3`，保留原有共享资料。
- 旧桌面长期记忆保留在原目录，不自动导入独立库或共享库。

备份分别保存账号快照、身份清单和共享库；不会把账号库合并到桌面记忆。独立库快照内保存账号归属、稳定记录 ID、版本及删除状态，错标为其他账号的快照会被拒绝。

本机向云端上传不能替换已有管理员或共享资料。空的新安装可从已认证本机的首次备份恢复原管理员；后续上传不能转交权限。云端下载作为共享库的权威副本，保留资料编号与删除状态。

worker 模式下的共享命令转交云端执行；若账号身份尚未同步，拒绝执行并提示等待同步，避免读写另一个独立的共享库。共享命令不支持离线写入队列。

## 权限边界

账号隔离覆盖记忆接口、普通聊天、自动记忆、定时任务和备份同步。这不是操作系统沙箱：现有“完整远程操控”能够使用整机文件和代码能力。若需要防止拥有这些能力的账号绕过应用接口直接访问数据库，必须限制完整远程权限或使用独立系统用户/服务进行隔离；仅分库不能提供这项保证。

普通聊天模式仅提供账号记忆工具，适合需要保持记忆权限边界的账号。桌面管理员以及持有云端桥接凭据的本机服务属于可信管理端，可备份所有库。
